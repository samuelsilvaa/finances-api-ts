# Finances API

API REST para controle financeiro pessoal: cadastro de usuários, categorias e transações, com resumo de saldo e gastos por período.

> **Status:** em desenvolvimento

## 🛠️ Tecnologias

- Node.js
- TypeScript
- Express
- PostgreSQL
- Prisma
- Docker
- Swagger

## Funcionalidades

- [ ] Autenticação (cadastro e login com JWT)
- [ ] CRUD de categorias
- [ ] CRUD de transações
- [ ] Resumo financeiro por mês
- [ ] Documentação com Swagger
